base_link高さ(z)の算出過程:
  確定仕様(base_footprint基準): 車輪半径0.040 / 主板上面z=0.060
  base_linkを主板の板厚を表す薄い箱と定義:
    下面 = 車輪中心高さ(接地条件より車輪半径と一致) = 0.040
    上面 = 主板上面 = 0.060
    板厚 = 0.060 - 0.040 = 0.020
    base_link原点(中心)z = (0.040 + 0.060) / 2 = 0.050
  以降、各子リンクのjoint origin zは「絶対値(base_footprint基準)-0.050」で算出:
    車輪: 0.040 - 0.050 = -0.010
    arm_base: 0.060 - 0.050 = 0.010
    oak_d: 0.197 - 0.050 = 0.147
    lidar: 0.210 - 0.050 = 0.160

■ タスク3: LiDARフィルタの見直し

除去角度セクターの算出根拠(src/amr_bringup/scripts/lidar_filter.pyの
docstringに算出過程の全文を記載、以下は要約):

  1. 方位(base_link座標系):
     arm_base=(0.150,0)   → bearing = -2.401°、距離0.3103m(仕様の0.31mと一致)
     arm_ext =(0.350,0)   → bearing = -1.460°、距離0.5102m(仕様の0.51mと一致)
       (arm_extはarm_baseから+X方向に0.20m伸展した仮定点)
     中心方位 = -1.931°、伸展による方位ぶれの半値幅 = 0.471°
  2. アーム太さによる角度幅:
     so101_arm.xacroのlink2断面(0.036×0.032、アーム中最も太いピッチ軸
     リンク)の対角線=0.0482mを実効アーム径として採用。
     最も角度幅が大きくなる最近接距離0.31mで評価:
     half_angle = atan(0.0241/0.31) = 4.438°
  3. 合計半値幅 = 4.438 + 0.471 + 0.5(安全マージン) = 5.409°
     → 全幅 約10.82°(360°全周除去だった旧min-range方式に対し大幅に限定)
  4. LiDAR自身の角度系への変換(laser_frameはyaw+90°回転して取付):
     中心 = -1.931 - 90 = -91.931°
     除去セクター = [-97.340°, -86.522°] = [-1.6989, -1.5101] rad
  距離閾値: 0.60m(伸展時最大0.51m + 安全マージン0.09m)

  実装: LaserScanコールバックでangle_min+i*angle_incrementが上記セクター内
  かつ range<0.60m の点のみinfに置換。セクター外・0.60m以遠は温存するため、
  旧来の全周min-range方式(0.28m未満を一律除去)より探知能力の低下を
  最小限に抑えている。

     最多到達点数(51点)を記録した。pitch=45°への変更を検討する価値あり。
     ただし到達点数だけでなく、実際のIK解の姿勢的な妥当性(グリッパーが
     ゴミを挟みやすい角度か等)は別途確認が必要。
  3. Pre-grasp高さ:
     高さスキャンの結果、x=0.40,y=0.00が最も広い到達z範囲(0.02〜0.20m
     全域)を示した。Pre-grasp高さの具体的な値(例:z=0.10〜0.16m程度の
     中間高さ)は、実際の把持シーケンス設計と合わせて人間が決定すること。
  4. 名前付きポーズ: 上記1〜3が決まった後、対応するjoint角度セット
     (HOME/APPROACH/GRASP等)を再定義する必要がある。
